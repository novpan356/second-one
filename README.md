# TEKKEN ATLAS

铁拳 8 角色与战斗资料查询界面，采用留白、克制配色、清晰的内容层级与连贯动画。基于 React 19 / Vite 7，支持手机与桌面、中英日界面和原创编辑摘要。

## 运行

要求 Node.js 22.12+（当前机器为 24.19）。

```bash
cd /workspace/second-one
npm --cache /workspace/.npm-cache ci --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
```

```bash
npm run build
npm test
npm run test:ui
```

浏览器测试使用 `/usr/bin/chromium`，可通过 `ATLAS_TEST_URL` 指向其他测试地址。截图保存于 `/tmp/tekken-atlas-checks`。UI 用 hash 路由，静态服务器无需额外 rewrite；可分享某个角色或标签的 fragment URL。

## 已实现

- 41 个社区角色条目：32 位基础阵容，S1 / S2 DLC 与社区国光 S3 条目；不是已通过官网核验的最新发布名单。
- 全条目角色图片、人物档案、原创三语背景摘要、流派与国籍。
- 招式检索、判定筛选、发生排序、防御数字筛选、详情与输入图解、发生/防御/打中/反击帧数展示。
- 连段目录、类别筛选和指令复制。
- 确反速度候选：排除连拳延伸帧、架势输入及复杂最速指令；站立与起身分开。距离、输入耗时与姿态仍需训练模式验证，候选不是保证确反。
- P1 / P2 左右横移输入说明，以及依据原文 Homing 标记筛选的追踪招式；不推断未核实的逐招避招方向。
- 28 位选手的三语简介、历史角色关联、筛选和外部资料链接；不声称当前角色归属或比赛成绩已实时核验。
- 商城资料栏目和更新栏目，均明确展示资料缺口；不编造价格、库存、S3 平衡改动或完整补丁历史。
- 收藏和语言本地保存、响应式布局、动画、键盘操作、弹窗焦点管理，以及减少动态效果偏好支持。

## 数据限制与后续必要工作

官网及 Wavu 实时网站的访问被当前云环境网络 allowlist 拒绝（HTTP CONNECT 403）。目前完成的是可运行查询应用及社区快照接入，尚不能宣布“最新 S3 / 全量历史更新 / 商城实时资料”已完成。

已在环境配置草稿保存官网、Wavu 等所需域名。需要在环境设置中保存并应用网络更改，然后继续：

1. 核对官方已发布与未发布角色名单，特别是 S3。
2. 核对最新补丁编号，按角色和指令导入正式更新明细；训练模式复验关键帧数与横移窗口。
3. 补全 Jun / Xiaoyu / Law / Clive / Kunimitsu 的打中、防御、反击等缺项。
4. 补全和核验官方故事、商城商品/地区/价格/上架时间及选手关联。
5. 整理原文招式名/备注的中日翻译。当前这些字段保留英文来源语言，不能声称内容已全部三语化。

41 份角色 JSON 在 `public/data`，不存在时不推断帧数；`gameVersion: null` 明确表示补丁未标定。`src/editorial.js` 管理自写三语摘要与选手关联，`src/i18n.js` 管理界面翻译。数据来源、图片来源及导入方式见 [SOURCES.md](SOURCES.md)。

当前数据是静态快照，无账号系统、真实商城交易或实时 API。未来的云任务使用现有 checkout，不需要 Git worktree。
