CONTROLS / INPUT

W A S D / 方向键
方向输入；A/D 沿画面移动，S 蹲姿，W 按住跳跃。
U / I / J / K
分别为 1 左拳、2 右拳、3 左脚、4 右脚。
Q / E
角色自身向左／右横移。触屏使用 SSL / SSR 按钮。
DF + 2
按住前下，再按 I。默认面对右侧时使用 D+S+I。
1,2 / 1,2,2
先按 U，再依次按 I。派生窗口为原型规则，非原版帧级还原。
同时按键
同时按 J+K 为 3+4；U+J 为 1+3；I+K 为 2+4。
R / H / B / P
重置 / 判定体 / 骨骼 / 暂停。鼠标拖动场景可转动镜头。
